## О репозитории

Данный репозиторий содержит выполнение лабораторных работ по дисциплине «Практикум по программированию». Проекты структурированы по отдельным директориям, каждая из которых представляет собой законченное модульное приложение с собственной документацией, архитектурой и набором автоматизированных тестов.

## Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/shakirovaleksandrrr/PPP26-27_1sem_SHAS.git
cd PPP26-27_1sem_SHAS
```

### 2. Активация общего виртуального окружения
**Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Запуск лабораторных работ
- **Лабораторная работа 3.1 (Звездное поле):**
  ```powershell
  python lab3_1/main.py
  ```
  *Тесты:* `python -m unittest discover lab3_1/tests -v`

- **Лабораторная работа 3.2 (Алгоритм A\*):**
  ```powershell
  python lab3_2/main.py
  ```
  *Тесты:* `python -m unittest discover lab3_2/tests -v`
