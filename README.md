## Описание проекта

Программа представляет собой интерактивную анимацию трехмерного звездного поля, созданную на базе графической библиотеки Tkinter. Симуляция моделирует полет космического корабля сквозь космическое пространство с реалистичной перспективной проекцией, эффектом световых шлейфов гиперпрыжка (warp speed) и возможностью свободного маневрирования с помощью мыши и клавиатуры.

---

## Функциональные возможности

### Основной функционал
- 🌌 **3D-перспектива:** Проекция трехмерных координат звезд $(X, Y, Z)$ на двумерную плоскость экрана.
- 📏 **Динамический размер:** Размер звезд обратно пропорционален расстоянию до наблюдателя (чем ближе звезда, тем она крупнее).
- 🎨 **Цветовая дифференциация:** Звезды обладают реалистичными спектральными оттенками (холодный белый, голубой, желтоватый) с динамической яркостью.
- ⚡ **Световые шлейфы (Warp Trails):** Отрисовка траектории движения звезд от предыдущей позиции к текущей, создающая кинематографичный эффект гиперпрыжка.
- 🔄 **Бесшовный респавн:** Автоматическое перерождение звезд в дальней плоскости при выходе за пределы экрана или пролете за камеру.

### Дополнительный функционал
- 🖱️ **Интерактивное пилотирование мышью:** Курсор мыши задает направление полета (смещение фокуса и точки схода).
- ⌨️ **Управление скоростью с клавиатуры:** Плавное ускорение и торможение клавишами `W`/`S` или стрелками `Вверх`/`Вниз`.
- ⏯️ **Пауза и сброс:** Мгновенная остановка анимации по клавише `Space` и сброс параметров к исходным значениям по клавише `R`.
- 🎛️ **Панель управления (UI Controls):** Слайдеры для регулировки скорости, количества звезд и переключатель световых шлейфов в реальном времени.
- 🧪 **Модульное тестирование:** Покрытие математической модели перспективной проекции и логики респавна unit-тестами.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/username/lab3_1_starfield.git
cd lab3_1_starfield
```

### 2. Создание и активация виртуального окружения
**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**
```cmd
python -m venv venv
venv\Scripts\activate.bat
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Запуск тестов
```bash
python -m unittest discover tests -v
```

## Управление

| Клавиша / Действие | Действие |
| :--- | :--- |
| `Space` (Пробел) | Пауза / Возобновление анимации |
| `R` / `r` | Сброс положения звезд и параметров камеры |
| `W` / `Стрелка вверх` | Увеличение скорости полета |
| `S` / `Стрелка вниз` | Уменьшение скорости полета |
| `Движение мыши` | Изменение вектора движения (управление точкой схода) |
| `Слайдер скорости` | Плавная регулировка скорости полета |
| `Слайдер звезд` | Настройка количества звезд на экране |
| `Чекбокс Warp Trails`| Включение/отключение световых шлейфов |

## Структура проекта

```text
lab3_1/
├── .gitignore                   # Исключение временных файлов кэша
├── README.md                   # Документация, титульные данные и руководство
├── requirements.txt            # Список зависимостей
├── main.py                     # Точка входа в программу
├── src/
│   ├── __init__.py
│   ├── app.py                  # Главный класс приложения Tkinter и анимационный цикл
│   ├── models/
│   │   ├── __init__.py
│   │   ├── star.py             # Модель отдельной звезды (3D-координаты, цвет, шлейф)
│   │   └── starfield_model.py  # Математическая модель 3D-проекции и физики
│   ├── renderers/
│   │   ├── __init__.py
│   │   └── star_renderer.py    # Рендерер графических примитивов на Canvas
│   └── widgets/
│       ├── __init__.py
│       └── controls.py         # Панель пользовательского интерфейса (слайдеры, кнопки)
└── tests/
    ├── __init__.py
    └── test_model.py           # Unit-тесты для математической модели
```

**Назначение основных модулей:**
- `main.py` — инициализация и запуск приложения.
- `app.py` — класс `StarfieldApp`, отвечает за главное окно, обработку системных событий и таймер анимации `root.after`.
- `starfield_model.py` — класс `StarfieldModel`, содержит математику перспективного проецирования и физику перемещения в пространстве.
- `star_renderer.py` — класс `StarRenderer`, осуществляет отрисовку звездных дисков и векторных линий шлейфа.
- `controls.py` — класс `ControlsFrame`, панель интерактивного управления параметрами.
- `test_model.py` — проверка корректности математических формул и граничных условий движения.
