## Описание проекта

Программа представляет собой интерактивную анимацию и сравнительный стенд алгоритмов поиска кратчайшего пути на двумерной дискретной сетке. Основным объектом исследования является алгоритм $A^*$ ($A\text{-Star}$), использующий эвристическую оценку расстояния, в сравнении с классическим алгоритмом Дейкстры, поиском в ширину (BFS) и жадным поиском (Greedy Best-First Search). Программа позволяет генерировать сложные лабиринты, рисовать препятствия мышью, экспортировать и импортировать карты в текстовые файлы, а также отслеживать прогресс поиска в пошаговом или непрерывном режиме.

## Функциональные возможности

### Основной функционал
- 🧭 **Алгоритм A\* (A-Star):** Оптимальный поиск пути по формуле $f(n) = g(n) + h(n)$ с эвристиками Манхэттена и Евклида.
- 🎨 **Цветовая дифференциация состояний:**
  - 🟢 **Старт (Start):** Зеленый цвет.
  - 🔴 **Цель (Goal):** Красный цвет.
  - 🔵 **Открытый список (Open Set):** Голубой / бирюзовый цвет (очередь кандидатов на исследование).
  - 🟣 **Закрытый список (Closed Set / Visited):** Фиолетовый / темно-синий цвет (уже исследованные узлы).
  - 🟡 **Кратчайший путь (Shortest Path):** Золотистый / желтый цвет (восстановленная оптимальная траектория).
  - ⬛ **Стены / Препятствия (Obstacles):** Темно-серый / графитовый цвет.
- 🎬 **Анимационный цикл:** Плавное пошаговое или непрерывное отображение распространения фронта поиска с регулировкой скорости.
- 🔄 **Восстановление пути:** Плавная анимация обратного прохода от цели к старту при успешном нахождении маршрута.

### Дополнительный функционал
- 📊 **Сравнение алгоритмов:** Переключение между $A^*$, алгоритмом Дейкстры ($h(n) = 0$), BFS (поиск в ширину) и Greedy Best-First ($f(n) = h(n)$) в один клик.
- 🧩 **Генератор лабиринтов:** Автоматическое построение идеальных лабиринтов алгоритмом Recursive Backtracker (поиск с возвратом) и генерация случайных препятствий.
- 💾 **Импорт и экспорт карт:** Сохранение структуры лабиринта в текстовые файлы формата `.txt` и загрузка сохраненных карт из каталога `maps/`.
- 🖱️ **Интерактивный редактор:** Рисование стен левой кнопкой мыши, удаление правой кнопкой мыши, перетаскивание старта и финиша.
- 📈 **Телеметрия в реальном времени:** Отображение длины найденного пути, количества исследованных ячеек (посещений) и времени выполнения.
- 🧪 **Модульное тестирование:** 100% покрытие математической и логической части алгоритмов поиска unit-тестами.

## Управление

| Клавиша / Действие | Действие |
| :--- | :--- |
| `Space` (Пробел) | Запуск / Пауза анимации поиска пути |

| `Shift + ПКМ` | Перемещение целевой точки (красная) |
| `Слайдер задержки` | Регулировка скорости анимации (мс на шаг) |
| `Выпадающий список` | Выбор алгоритма поиска ($A^*$, Dijkstra, BFS, Greedy) |

## Структура проекта

```text
lab3_2/
├── .gitignore                   # Исключение временных файлов кэша
├── README.md                   # Документация, титульные данные и руководство
├── requirements.txt            # Указание зависимостей (стандартная библиотека)
├── main.py                     # Точка входа в программу 3.2
├── maps/                       # Сохраненные текстовые файлы лабиринтов
│   ├── simple_maze.txt
│   └── complex_maze.txt
├── src/
│   ├── __init__.py
│   ├── app.py                  # Главный класс PathfindingApp (окно Tkinter, события, таймер)
│   ├── models/
│   │   ├── __init__.py
│   │   ├── node.py             # Модель ячейки сетки (координаты, g, h, f, типы)
│   │   ├── grid.py             # Модель 2D-сетки (стены, генератор лабиринтов, экспорт/импорт)
│   │   └── pathfinders.py      # Реализация алгоритмов A*, Dijkstra, BFS, Greedy Best-First
│   ├── renderers/
│   │   ├── __init__.py
│   │   └── grid_renderer.py    # Отрисовка клеток, градиентов посещений и пути на Canvas
│   └── widgets/
│       ├── __init__.py
│       └── controls.py         # Панель управления (кнопки, слайдеры, селекторы алгоритмов)
└── tests/
    ├── __init__.py
    └── test_pathfinding.py     # Модульные тесты алгоритмов поиска и эвристик
```

**Назначение основных модулей:**
- `main.py` — запуск приложения `PathfindingApp`.
- `node.py` — класс `Node`, инкапсулирует состояние отдельной клетки сетки (координаты, стоимости $g, h, f$, ссылка на родителя для восстановления пути).
- `grid.py` — класс `Grid`, управляет матрицей узлов, генерацией идеальных лабиринтов (DFS/Recursive Backtracker) и текстовой сериализацией в `.txt`.
- `pathfinders.py` — классы поиска `AStarFinder`, `DijkstraFinder`, `BFSFinder`, `GreedyBestFirstFinder` с интерфейсом пошаговых генераторов `step()`.
- `grid_renderer.py` — класс `GridRenderer`, быстрый рендеринг сетки и HUD-статистики.
- `controls.py` — класс `ControlsFrame`, кнопки генерации, экспорта/импорта, паузы и слайдер скорости.
